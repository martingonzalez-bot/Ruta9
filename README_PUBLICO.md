# RUTA 9 — Demo completa pública

Repositorio:
https://github.com/martingonzalez-bot/Ruta9

Esta rama contiene una demo integrada de **RUTA 9 + AR + ADMIN + Y7**.

## Rutas de demo
- Menú: `/`
- Admin público: `/admin/`
- Y7: `/y7.html`

## Catálogo
El archivo `data.js` contiene 57 productos reales del proyecto actual:
25 Burgers + 7 Snacks + 15 Papas + 1 Burger Factory + 10 Extras.

## Funciones de reunión
- Menú y categorías
- Detalle de producto
- AR demo para los 57 productos
- Escala, rotación, movimiento y exploración por capas
- Carrito
- Dashboard Admin
- Gestión y filtros de productos
- Previsualización/configuración AR
- Gestión de campañas Y7
- Demo Y7 con contexto RUTA 9
- Puntos e historial mediante localStorage para la demo

## Importante
Los puntos, cambios del admin y estado del catálogo son locales al navegador para permitir una demostración autónoma. La integración real de backend, autenticación y puntos deberá conectarse posteriormente sin cambiar la experiencia visual.
