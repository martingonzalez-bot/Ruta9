# Ruta 9 — paquete público editable

Este paquete incluye el proyecto estático editable, referencias/documentación y una interfaz `/admin/` pública para editar productos localmente y descargar un `data.js` actualizado.

No contiene credenciales reales.

Para convertirlo en un proyecto con URL pública editable por colaboradores, subirlo a GitHub como repositorio público y activar GitHub Pages. La persona que vaya a editar el código debe ser colaboradora con permisos de escritura.
